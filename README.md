# Marc Mendez Roca

I'm a software engineer and data scientist based in Barcelona. My public work spans developer tooling, applied machine learning, and optimization.

## Featured project

[**Aplomo**](https://github.com/marcmendez/aplomo) helps Cursor, Codex, and Claude Code find and reuse the patterns already in a codebase. It combines a repository-owned pattern catalog, bounded search, and advisory diff checks. I built it around a question I care about: how can we make an agent's changes easier to review as a project grows?
